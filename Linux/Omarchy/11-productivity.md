# 11 — Productivity (Omarchy)

**Profiles:** productivity

Already included: Obsidian, LibreOffice, LocalSend, mpv, Nautilus, screenshot/recording tools,
the Walker/launcher menu, web apps (HEY, Basecamp, ChatGPT, etc.), and 1Password-style service
installers. **Check before adding anything.**

Optional installers that ship with Omarchy (ask):
`omarchy-install-service-1password`, `-signal`, `-spotify`, `-dropbox`, `-tailscale`;
`omarchy-webapp-install` (turn any site into an app).

Extras via `pkg`/`aurpkg`/`flat`: Bitwarden (`pkg bitwarden`), Slack (`flat com.slack.Slack`),
Discord (`pkg discord`), Zoom (`flat us.zoom.Zoom`), OBS (`pkg obs-studio`), draw.io
(`aurpkg drawio-desktop-bin`), Syncthing (`pkg syncthing`), CopyQ (`pkg copyq`).
